What the thing actually is

Strip away the framing and it is one markdown file. The frontmatter declares a name of humanizer, a version of 2.1.1, a description telling the agent to use it when editing or reviewing text, and a list of allowed tools: read, write, edit, grep, glob and a question prompt for the user. The published install instruction is to save it to a humanizer folder inside your skills directory as SKILL.md, after which the agent loads it whenever a task looks like editing. There is a public repository hosting the same file, and a copy published as a template on a third-party skills library. Nothing compiles, nothing runs as a service, and there is no account anywhere in the chain.

Twenty-four patterns, and where they come from

The headline claim is 24 distinct AI writing patterns, and the provenance is stated openly: Wikipedia's guide to the signs of AI writing, maintained by the project that cleans up AI text on the encyclopedia. That matters, because it means the list was assembled by people who read thousands of such edits rather than by a vendor guessing. The frontmatter names a good portion of them directly: inflated symbolism, promotional language, superficial analyses built on -ing clauses, vague attributions, overuse of the em dash, the rule of three, a vocabulary of characteristic AI words, negative parallelisms, and pile-ups of conjunctive phrases. The first content pattern in the file is about undue emphasis on significance, listing tells like stands as, serves as, is a testament to, and underscores its importance.

The half most copies leave out

Halfway down the file the instructions stop being a checklist and start being an argument, and this is the part worth reading even if you never install it. Removing bad patterns, it says, is only half the job, because sterile voiceless writing is just as recognisable as the obvious stuff. Its list of soulless tells is uncomfortably accurate: every sentence the same length, neutral reporting with no opinions, no acknowledgement of uncertainty, no first person where first person belongs, no humour. The remedies are concrete rather than vague. Have opinions and react to facts instead of listing them. Vary rhythm, with short sentences next to long ones. Say when you have mixed feelings. Use the word I when it is honest. Allow a tangent. Be specific about the feeling rather than labelling it concerning.

Claims it carefully does not make

Nowhere does the file promise to beat a detector, produce a particular score, or make text undetectable, and that absence is worth noticing given how the keyword is usually sold. It targets a reader's impression, not a classifier's output, and those two goals diverge more than people expect. Two other practical notes. The publicly circulated version is explicitly a template containing placeholder values such as your name and a content directory, which have to be replaced before the skill is useful. And because the allowed tools include write and edit, the agent can change files directly, so run it on a branch or a copy the first time rather than across a folder of finished work you have not backed up.

Installing and running it without surprises

  1. Read the file before you save it
    It is short, and the second half is the part that matters. You will also spot the placeholder values that need replacing with your own name and paths.
  2. Save it as SKILL.md
    Put it in a humanizer folder inside your agent's skills directory. The frontmatter handles the rest, so the skill loads when a task looks like editing or reviewing text.
  3. Point it at a copy first
    Its allowed tools include write and edit, so it can change files in place. Run the first pass on a branch or a duplicate until you know how aggressive the rewrite is.
  4. Check the voice pass separately
    Removing patterns and adding personality are two different edits. Read the output specifically for whether it now has an opinion, not just whether the em dashes are gone.

FAQ

Does the humanizer skill beat AI detectors?

It never claims to. The file targets stylistic patterns a human reader notices, using a list drawn from Wikipedia's signs of AI writing guide, and says nothing about classifier scores or detection rates. Treat any promise of undetectability attached to this keyword as coming from somewhere other than this file.

Where do I install it?

Save the file as SKILL.md inside a folder named humanizer in your agent's skills directory, which is the path the publisher gives. The frontmatter describes when the skill should trigger, so there is no command to register and nothing else to configure once the placeholders are replaced.

What patterns does it look for?

Twenty-four in total. The frontmatter names inflated symbolism, promotional language, superficial analyses built on -ing clauses, vague attributions, em dash overuse, the rule of three, characteristic AI vocabulary, negative parallelisms and excessive conjunctive phrases, with the first content section covering undue emphasis on significance.

Is it safe to run on a folder of drafts?

Be careful the first time. Its declared tool list includes write and edit, which means it can modify files directly rather than printing a suggested version. Run it against a branch or a copy until you have seen how much of your own phrasing it is willing to replace.

Do I need a subscription for it?

No. It is a plain markdown file published openly, with a copy in a public repository and another on a third-party skills library. What it does require is an agent capable of loading skills and editing local files, which is where the actual cost sits.
