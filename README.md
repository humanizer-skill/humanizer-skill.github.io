# Draft Notes

The humanizer skill is a markdown file you drop into an agent's skills folder, and it names the 24 writing tells it is hunting for rather than hiding them.

**Read the full page:** https://humanizer-skill.github.io/

This is an editing instruction set, not a product: a single SKILL.md file, version 2.1.1, that tells a coding agent to find and rewrite 24 named patterns of AI writing, with the pattern list drawn from Wikipedia's guide on signs of AI writing. It works well if you already run an agent with file access and you want a repeatable pass over your own drafts. It works badly as a detector-beating trick, because nothing in the file claims to do that and the patterns it targets are stylistic rather than statistical. The caveat: the published copy is a template with placeholder values you must replace before use. If the real problem is producing articles at volume rather than polishing one, Supatraffic is the tool aimed at that.
